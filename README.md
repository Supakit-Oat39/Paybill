# Bill Splitter (หารบิล)

เว็บแอปหารค่าใช้จ่ายในกลุ่มเพื่อน แบบ Mobile-first ไม่ต้อง Login ไม่มี Backend
เก็บข้อมูลใน LocalStorage และกรอกช่องทางรับเงิน (พร้อมเพย์ / บัญชีธนาคาร / รูป QR) ของแต่ละคนได้

## โครงสร้างไฟล์

```
Paybill/
├── index.html              หน้าเว็บ (2 หน้าหลัก: รายการบิล / สรุปและคำนวณ + เมนูล่าง)
├── css/styles.css          ดีไซน์ทั้งหมด (โทนพาสเทล เขียว ฟ้า ครีม)
├── js/
│   ├── app.js              UI: ฟอร์ม, bottom sheet, หน้าต่างยืนยัน, ช่องทางรับเงิน, สำรอง/กู้คืน
│   ├── calc.js             สูตรคำนวณ (หารเท่ากัน, กระจายเศษสตางค์, ยอดสุทธิ, รายการโอน)
│   ├── money.js            แปลง/แสดงเงิน (ภายในใช้หน่วยสตางค์ทั้งหมด)
│   ├── state.js            จัดการสมาชิก/รายการ, ลบสมาชิกแบบปลอดภัย, ส่งออก/นำเข้า JSON
│   ├── storage.js          บันทึก LocalStorage อัตโนมัติ
│   └── payment.js          ช่องทางรับเงิน: ตรวจพร้อมเพย์/เลขบัญชี, รายชื่อธนาคาร, จัดรูปแบบ
├── scripts/serve.mjs       เซิร์ฟเวอร์ทดสอบบนเครื่อง (ไม่ต้องติดตั้งอะไร)
├── tests/                  Unit tests (สูตรคำนวณ, จัดการข้อมูล, ช่องทางรับเงิน)
└── tests/e2e/              End-to-end test บนเบราว์เซอร์จริง (Playwright)
```

ไม่มีขั้นตอน build — เป็นไฟล์ static ล้วน นำไปวางบน static hosting ได้ทันที

## เปิดใช้งานบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป (ใช้เปิดเซิร์ฟเวอร์ทดสอบเท่านั้น)

```bash
cd Paybill
npm start            # เปิด http://localhost:5173
```

> ต้องเปิดผ่าน http:// (ไม่ใช่ดับเบิลคลิกไฟล์ index.html) เพราะใช้ JavaScript modules
> ถ้าไม่มี Node ใช้ `python3 -m http.server 5173` แทนได้
>
> ทดสอบบนมือถือ: ให้มือถืออยู่ Wi-Fi เดียวกัน แล้วเปิด `http://<IP ของคอมพิวเตอร์>:5173`

## หลักการคำนวณ (สรุป)

- ทุกรายการ (อาหาร, น้ำ, SC, VAT, ค่าส่ง) ใช้สูตรเดียวกัน: `ราคา ÷ จำนวนผู้ร่วมรับผิดชอบ`
- คำนวณเป็น **สตางค์ (จำนวนเต็ม)** ไม่มีปัญหาทศนิยมคลาดเคลื่อน
- เศษสตางค์ +1 ให้คนที่ได้รับเศษน้อยที่สุดจนถึงตอนนั้นก่อน จึงไม่ตกที่คนเดิมทุกรายการ ผลรวมส่วนแบ่งเท่ากับราคาพอดี
- `ยอดสุทธิ = จ่ายจริง − รับผิดชอบ` (บวก = ต้องได้รับ, ลบ = ต้องจ่ายเพิ่ม)
- รายการโอน: จับคู่ยอดที่เท่ากันพอดีก่อน แล้วจับคู่ยอดมากสุดกับยอดมากสุด จำนวนการโอนไม่เกิน (จำนวนคนที่มียอดค้าง − 1)

## ข้อจำกัดที่ยังมี

**ช่องทางรับเงิน**
- ขั้นตอนใช้งาน: เพิ่มสมาชิก → เพิ่มรายการ → กรอกช่องทางรับเงิน (ไม่บังคับ) ซึ่งกรอกได้ที่หน้าสรุปผลเท่านั้น และแสดงเฉพาะคนที่ต้องได้รับเงิน
- ปุ่ม "แชร์สรุปผล" เปิดเมนูแชร์ของเครื่อง เลือกส่งไปแอปไหนก็ได้ (LINE, Messenger, Instagram, ข้อความ ฯลฯ) พร้อมแนบรูป QR ถ้ามี — แต่ละแอปรับข้อมูลไม่เหมือนกัน บางแอปรับแค่รูปหรือแค่ข้อความ
- คอมพิวเตอร์ที่ไม่มีเมนูแชร์ ปุ่มแชร์จะคัดลอกข้อความแทน ข้อความที่คัดลอกใส่ได้แค่ตัวหนังสือ รูป QR ต้องกด "บันทึกรูป QR" แล้วส่งเอง
- รูป QR ถูกย่อและเก็บใน LocalStorage (ประมาณ 100–300 KB ต่อรูป) และรวมอยู่ในไฟล์สำรอง JSON

**ข้อมูล**
- LocalStorage อยู่ในเบราว์เซอร์และอุปกรณ์นั้นเท่านั้น ไม่ซิงก์ข้ามเครื่อง ถ้าล้างข้อมูลเว็บไซต์ข้อมูลจะหาย ควรส่งออกไฟล์สำรอง
- รองรับ 1 กลุ่ม/ทริปต่อเบราว์เซอร์ (ถ้าจะเริ่มทริปใหม่ ให้ส่งออกไฟล์เก่าเก็บไว้ แล้วล้างข้อมูล)
- การโอนใช้วิธีจับคู่ที่ได้จำนวนการโอนน้อยในกรณีทั่วไป แต่ไม่รับประกันว่าน้อยที่สุดในทุกกรณี (ปัญหานี้ในทางทฤษฎีคำนวณยากมาก)
